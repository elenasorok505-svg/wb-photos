# Категории Anklavia — откуда брать таблицы

`anklavia-categories-2026-10-28.xlsx` — полный справочник: 25 разделов, 1655 листовых категорий
(slug, 中文), характеристики каждой категории (тип, обязательность, словарь значений) и словари.
Пользователь больше не присылает шаблон на каждую категорию — берём отсюда.

Порядок работы: взять раздел/подраздел → `python3 cats.py leaves "Раздел › Подраздел"` →
по каждой подкатегории сделать таблицу (конвейер скилла anklavia-1688-cards).

* `python3 cats.py fields SLUG` — какие поля заполнять и допустимые значения (значения брать из словаря).
* `python3 cats.py tpl SLUG <папка>/tpl.xlsx` — шаблон. Официальные шаблоны лежат как `tpl_SLUG.xlsx`
  (сейчас: bags, dresses, lampshades, women-tshirts). Для остальных шаблон собирается по образцу;
  коды колонок ([attr:…] в ряду 2) известны не для всех полей — скрипт перечислит недостающие.
  Получив официальный шаблон новой категории, положите его сюда как `tpl_SLUG.xlsx` — коды из него
  подхватятся и для других категорий.
